# Hina Glow

A private birthday orbit for Hina — a five-level interactive surprise journey built with Vite and TypeScript.

## Run locally

```bash
npm install
npm run dev
```

## Build for Vercel

```bash
npm run build
```

Vercel is configured through `vercel.json` to use the Vite build output in `dist`.

## Highlights

- Five interactive birthday chapters
- Galaxy-heart constellation surprises
- Heart-shaped wish reveal modal
- Cake slicing with asset-based cake artwork, fireworks, confetti, and sound
- Candle extinguishing after five taps or three motion waves
- Staged ring-gifting finale

The referenced Flaticon artwork is credited within the project where required.
